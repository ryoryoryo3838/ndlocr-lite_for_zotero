# NDLOCR-Lite for Zotero

国立国会図書館の OCR「NDLOCR-Lite」で PDF を文字認識し、そのテキストを Zotero の全文インデックスに登録するプラグインです。スキャンした PDF でも、Zotero の検索で本文の語句から見つけられるようになります。

- OCR した文字を見えない層（透明テキスト）として PDF に追記します。PDF ビューアで検索語のハイライトや文字の選択ができるようになります。元の PDF のデータには手を加えず末尾に追記するだけなので、しおりや文書情報も残ります
- 元の PDF はバックアップし、右クリック 1 回で元に戻せます（設定で、元の PDF はそのままにして別の添付として追加することもできます）
- OCR の計算はこのパソコンの中で行います（GPU 不要）。結果はユーザー自身の Zotero の全文同期・ファイル同期の設定によって、Zotero の同期先（Zotero のサーバーや、ファイル同期で設定した WebDAV サーバー）に送られることがあります。このプラグイン独自のサーバーには送信しません
- 対応: Zotero 7〜10 / macOS 13 以降・Windows・Linux（Debian 12 で NDLOCR-Lite のインストールと OCR を確認。`curl` と `unzip` が必要）。macOS は実機の Zotero での動作をまだ確認していません

## 1. プラグインを Zotero に入れる

1. [最新のリリース](https://github.com/ryoryoryo3838/ndlocr-lite_for_zotero/releases/latest) から `ndlocr-lite_for_zotero-<版>.xpi` をダウンロードする（Firefox で開くとブラウザに追加しようとするので、リンクを右クリック →「名前を付けてリンク先を保存」）
2. Zotero で「ツール → プラグイン」を開く
3. 右上の歯車 →「ファイルからプラグインをインストール…」で、ダウンロードした `.xpi` を選ぶ

新しい版が出ると、Zotero が自動で更新します（「ツール → プラグイン」の歯車 →「アップデートを確認」で手動でも確認できます）。

## 2. NDLOCR-Lite をセットアップする

「設定 → NDLOCR-Lite for Zotero」の「セットアップ…」を押し、インストールする場所を選びます。続けて、OCR で差し替える前の PDF をバックアップするかを選びます（既定はバックアップする。容量を節約したいときは「バックアップしない」。後から設定で変えられます）。選んだ場所の中に `ndlocr-lite-zotero` フォルダが作られ、Python、NDLOCR-Lite 本体とモデルがまとめて入ります（約 650MB をダウンロード。数分〜十数分）。終わるとインストール先が設定に入り、`✓ 動作確認 OK` と表示されます。この確認はプログラムの起動確認であり、OCR 処理の成功までは保証しません。

- 場所のパスには **日本語などの全角文字を含めないで** ください（NDLOCR-Lite が動かなくなることがあります）。Windows でユーザー名が日本語の場合は、`C:\` などを選んでください。
- パッケージ管理ツール uv がすでに入っていればそれを使い、なければ同じフォルダに入れます。ユーザーが uv や Python を事前にインストールする必要はありません。インストール時には一時フォルダも使い、通常は終了時に削除します。不要になったらインストール先のフォルダを削除できます。
- 途中で止めるときは、ツール →「NDLOCR: 実行中の OCR を中止」を選びます。
- 動作確認で `DLL load failed` と出た場合（Windows）は、[Microsoft Visual C++ 再頒布可能パッケージ](https://aka.ms/vs/17/release/vc_redist.x64.exe) をインストールしてから、もう一度「動作確認」を押してください。

### 更新・再インストール

もう一度「セットアップ…」を押し、既存の `ndlocr-lite-zotero` フォルダを選べば、足りないものを入れ直します。安全確認のため、旧版で作成した環境などで仮想環境の所有者を確認できない場合は上書きせず停止します。その場合は別の空の場所を選んでセットアップしてください。インストール後にフォルダを移動すると Python 環境が動かなくなります。移動したいときは、新しい場所でセットアップし直してください。

### インストーラを直接実行する場合

Zotero からのセットアップがうまくいかないときは、このリポジトリの [`installer`](https://github.com/ryoryoryo3838/ndlocr-lite_for_zotero/tree/main/installer) フォルダのインストーラを直接実行できます（リポジトリの「Code → Download ZIP」でまとめて取得できます）。終わったら、設定画面の「参照…」で作られた `ndlocr-lite-zotero` フォルダを選んでください（中のフォルダや、引用符付きのパスを貼り付けた場合も自動で直します）。

- macOS / Linux: ターミナルで `bash ` と入力し（最後に空白）、`install_mac.command` をドラッグ＆ドロップして Enter。macOS では Finder のダイアログで場所を選び、Linux ではインストール先のパスを入力します。
- Windows: `install_windows.cmd` をダブルクリックし、ダイアログで場所を選びます。
- NDLOCR-Lite の版を変えるときは、環境変数 `NDLOCR_VERSION`（例: `1.4.0`）を指定し、既存のインストール先とは別の空の場所にインストールします。

## 3. 使い方

| やりたいこと | 操作 |
|---|---|
| 選んだ PDF を OCR する（複数可・親アイテムを選べば中の PDF すべて） | 右クリック →「NDLOCR-Lite で OCR して全文インデックスに登録」 |
| ライブラリ内のテキストなし PDF をまとめて OCR する | ツール →「NDLOCR: このライブラリのテキストなし PDF をすべて OCR…」 |
| OCR をやり直す（既存のテキストを上書き） | 右クリック →「NDLOCR-Lite で再 OCR」 |
| 差し替えた PDF を元に戻す（OCR テキストでの検索は残す） | 右クリック →「NDLOCR: 差し替えた PDF を元に戻す」 |
| ライブラリ内の差し替えた PDF をすべて元に戻す | ツール →「NDLOCR: このライブラリの差し替えた PDF をすべて元に戻す…」 |
| OCR テキストの登録を外す（差し替えた PDF も元に戻す） | 右クリック →「NDLOCR の全文インデックスを解除」 |
| 実行中の処理を止める | ツール →「NDLOCR: 実行中の OCR を中止」 |

検索するときは、検索欄左のモードを「**すべて**」（Everything）にします。

まとめて OCR する場合、次の PDF は自動でスキップします。

- すでに文字のテキストがある PDF（既定では 100 文字以上。設定で変更可）
- このプラグインで OCR 済みの PDF
- ファイルがこの端末にない添付（同期だけされていて未ダウンロードのものなど）

速度の目安は、ノート PC で 1 ページ数秒です。数百件をまとめて処理すると数時間かかることがあります。

## 4. 設定

- **解像度 DPI**: PDF を画像にするときの解像度。既定値 150 は NDLOCR-Lite と同じです。小さい文字が多い資料は 300 にすると精度が上がることがありますが、遅くなります。
- **既存テキストとみなす文字数**: これ以上の文字があれば「テキストあり」としてスキップします。
- **同期でサーバーにも送る**: 新規インストールでは既定オフです。オンにすると、ユーザー自身の Zotero の全文同期で、OCR テキストが Zotero のサーバーにも送られ、同期している他の端末でも検索できます（Zotero の同期設定で「全文コンテンツを同期」がオンになっている必要があります）。既存の設定値は変更しないため、更新した場合は設定を確認してください。なお、この設定はファイル同期を制御しません。透明テキスト付き PDF を作り、Zotero のファイル同期が有効なら、その PDF と OCR テキストがユーザー自身のファイル同期先（Zotero または設定した WebDAV サーバー）に送られる場合があります。
- **透明テキスト付き PDF**: 次の 3 つから選びます。
  - 元の PDF と差し替える（既定）: 透明テキストを追記した PDF に差し替えます。「元に戻す」「解除」で元の PDF に戻します。変更を検知した場合は上書きしませんが、処理中の同時編集を完全には防げないため、OCR・復元中は他のアプリや端末で同じ PDF を変更しないでください。
  - 別の添付として追加する: 同じ親アイテムの下に「（OCR）」付きの添付として追加します。再 OCR すると、追加済みの添付のファイルを置き換えます（注釈は残ります）。
  - 作らない: Zotero の全文インデックスへの登録だけ行います。
- **差し替える前の PDF をバックアップする**（既定オン）: 元の PDF を Zotero データフォルダの `ndlocr-lite-backup` に保存します。バックアップは同期されず、OCR した端末にだけ残ります。安全のため復元後も自動削除しないので、不要になったものは内容を確認してから手動で削除してください。オフにした場合は、差し替えた PDF から追記分を取り除いて元に戻します。追記できなかった PDF（暗号化されたものなど）は、オフでも常にバックアップします。
- **再索引で上書きされたら自動で戻す**: 「アイテムの再索引」などで OCR テキストが PDF 本来の（ほぼ空の）テキストに置き換わったとき、保存しておいた OCR 結果で自動的に戻します。

## 5. 仕組み

1. PDF を作業用フォルダ（インストール先の `work`）にコピーし、NDLOCR-Lite で OCR します。
2. 認識結果を、添付の保存フォルダに `.zotero-ft-unprocessed` として置きます。これは、Zotero が全文同期で受け取ったテキストを置くのと同じ形式のファイルです。そのうえで Zotero 自身の索引処理（`Zotero.Fulltext.indexItems`）を呼び、検索用の索引に登録させます。
3. OCR 結果は `.zotero-ndlocr.json` として同じフォルダに残します。「解除」はこのファイルを消して索引を外します。
4. 透明テキスト付き PDF は、元の PDF の末尾に文字の層を追記（PDF の増分更新）して作ります。元の PDF のデータはそのまま残るので、しおり・文書情報・埋め込みの注釈なども引き継がれます。追記できない PDF（暗号化されたものなど）では、NDLOCR-Lite 標準の書き出しを使います。この場合、しおりと文書情報は引き継がれません。

## 開発

- `./build.sh` で `build/ndlocr-lite_for_zotero-<版>.xpi` を作ります。インストーラも `.xpi` に同梱します。
- `NDLOCR_DIR=<インストール先> node tests/plugin-harness.js` で、Zotero を模した環境でプラグインのコードを動かすテストを実行します（OCR は本物の NDLOCR-Lite を使います。未インストールならセットアップから行います）。テストは指定した場所でセットアップを実行するため、検証専用の場所を使ってください。
- `node --test tests/review-defaults.js tests/review-safety.js` と `python3 -B tests/test_installer_safety.py` で安全性の回帰テストを実行します。PDF 座標のテストは `NDLOCR_DIR=<インストール先> <インストール先>/.venv/bin/python -B tests/test_pdf_geometry.py` で実行できます。
- リリース: `plugin/manifest.json` の `version` を上げて main にマージし、`v<版>` のタグを push すると、GitHub Actions が `.xpi` と自動更新用の `updates.json` を作って Release に載せます。

## 注意

- 個人情報や医療データを含む PDF は、所属機関のデータ取扱いルールに従ってください（ローカルでの処理が認められていない資料には使わないこと）。OCR テキストは添付フォルダの `.zotero-ndlocr.json` に、元 PDF のバックアップは設定した場合 `ndlocr-lite-backup` に残ります。処理がクラッシュした場合、インストール先の `work` に作業コピーが残ることがあります。共有端末、バックアップ、ファイル同期の扱いに注意してください。
- 「解除」はこの端末の索引を外すだけです。ユーザー自身の Zotero の全文同期ですでに Zotero のサーバーへ送ったテキストは消えません。
- OCR の誤認識はそのまま検索結果に影響します。
