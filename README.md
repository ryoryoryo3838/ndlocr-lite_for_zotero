# NDLOCR-Lite for Zotero

国立国会図書館の OCR「NDLOCR-Lite」で PDF を文字認識し、そのテキストを Zotero の全文インデックスに登録するプラグインです。スキャンした PDF でも、Zotero の検索で本文の語句から見つけられるようになります。

- PDF ファイル自体は変更しません（透明テキスト層も付けません）
- OCR はすべてこのパソコンの中で行います（外部への送信なし。GPU 不要）
- 対応: Zotero 7〜10 / macOS・Windows

## 1. NDLOCR-Lite をインストールする

Python、NDLOCR-Lite 本体とモデルを、1 つのフォルダ（`ndlocr-lite-zotero`）にまとめて入れます（約 650MB）。パッケージ管理ツール uv がすでに入っていればそれを使い、なければ同じフォルダに入れます。フォルダの外には何も書き込まないので、不要になったらフォルダごと削除すれば元に戻ります。

インストールする場所は、ダイアログで選びます。選んだ場所の中に `ndlocr-lite-zotero` フォルダが作られます。場所のパスには **日本語などの全角文字を含めないで** ください（NDLOCR-Lite が動かなくなることがあります）。Windows でユーザー名が日本語の場合は、`C:\` などを選んでください。

インストールが終わると、インストール先のパスが表示され、クリップボードにもコピーされます。

### macOS

ターミナルを開いて `bash ` と入力し（最後に空白を入れる）、`installer` フォルダの `install_mac.command` をターミナルにドラッグ＆ドロップしてから Enter を押します。Finder のダイアログが開くので、インストールする場所を選んでください。

（`install_mac.command` をダブルクリックで開くと、「開発元を確認できない」と止められることがあります。その場合は上の方法で実行してください。）

### Windows

`installer\install_windows.cmd` をダブルクリックします。フォルダ選択のダイアログが開くので、インストールする場所を選んでください。

動作確認で `DLL load failed` と出た場合は、[Microsoft Visual C++ 再頒布可能パッケージ](https://aka.ms/vs/17/release/vc_redist.x64.exe) をインストールしてから、インストーラをもう一度実行してください。

### 更新・再インストール

インストーラをもう一度実行し、ダイアログで既存の `ndlocr-lite-zotero` フォルダを選べば、足りないものだけ入れ直します。NDLOCR-Lite の版を変えるときは、環境変数 `NDLOCR_VERSION`（例: `1.4.0`）を指定して実行します。

インストール後にフォルダを移動すると Python 環境が動かなくなります。移動したいときは、新しい場所でインストールし直してください。

## 2. プラグインを Zotero に入れる

1. Zotero で「ツール → プラグイン」を開く
2. 右上の歯車 →「ファイルからプラグインをインストール…」で `ndlocr-lite_for_zotero-0.1.1.xpi` を選ぶ
3. 「設定 → NDLOCR-Lite for Zotero」で、「参照…」から手順 1 の `ndlocr-lite-zotero` フォルダを選ぶ（クリップボードのパスを貼り付けても可）。選ぶと自動で動作確認され、`✓ 動作確認 OK` と出れば準備完了です。
   - 中のフォルダ（`ndlocr-lite` など）を選んだ場合や、パスを引用符付きで貼り付けた場合も、正しいフォルダに自動で直します。

## 3. 使い方

| やりたいこと | 操作 |
|---|---|
| 選んだ PDF を OCR する（複数可・親アイテムを選べば中の PDF すべて） | 右クリック →「NDLOCR-Lite で OCR して全文インデックスに登録」 |
| ライブラリ内のテキストなし PDF をまとめて OCR する | ツール →「NDLOCR: このライブラリのテキストなし PDF をすべて OCR…」 |
| OCR をやり直す（既存のテキストを上書き） | 右クリック →「NDLOCR-Lite で再 OCR」 |
| OCR テキストの登録を外す | 右クリック →「NDLOCR の全文インデックスを解除」 |
| 実行中の処理を止める | ツール →「NDLOCR: 実行中の OCR を中止」 |

検索するときは、検索欄左のモードを「**すべて**」（Everything）にします。

まとめて OCR する場合、次の PDF は自動でスキップします。

- すでに文字のテキストがある PDF（既定では 100 文字以上。設定で変更可）
- このプラグインで OCR 済みの PDF
- ファイルがこの端末にない添付（同期だけされていて未ダウンロードのものなど）

速度の目安は、ノート PC で 1 ページ数秒です。数百件をまとめて処理すると数時間かかることがあります。

## 4. 設定

- **解像度 DPI**: PDF を画像にするときの解像度。既定値 150 は NDLOCR-Lite と同じです。小さい文字が多い資料は 300 にすると精度が上がることがありますが、遅くなります。
- **既存テキストとみなす文字数**: これ以上の文字があれば「テキストあり」としてスキップします。
- **同期でサーバーにも送る**: オンにすると、OCR テキストが Zotero の全文同期でサーバーにも送られ、同期している他の端末でも検索できます（Zotero の同期設定で「全文コンテンツを同期」がオンになっている必要があります）。
- **再索引で上書きされたら自動で戻す**: 「アイテムの再索引」などで OCR テキストが PDF 本来の（ほぼ空の）テキストに置き換わったとき、保存しておいた OCR 結果で自動的に戻します。

## 5. 仕組み

1. PDF を作業用フォルダ（インストール先の `work`）にコピーし、NDLOCR-Lite で OCR します。
2. 認識結果を、添付の保存フォルダに `.zotero-ft-unprocessed` として置きます。これは、Zotero が全文同期で受け取ったテキストを置くのと同じ形式のファイルです。そのうえで Zotero 自身の索引処理（`Zotero.Fulltext.indexItems`）を呼び、検索用の索引に登録させます。
3. OCR 結果は `.zotero-ndlocr.json` として同じフォルダに残します。「解除」はこのファイルを消して索引を外します。

## 注意

- 個人情報や医療データを含む PDF は、所属機関のデータ取扱いルールに従ってください（ローカルでの処理が認められていない資料には使わないこと）。
- 「解除」はこの端末の索引を外すだけです。同期ですでにサーバーへ送ったテキストは消えません。
- NDLOCR-Lite は CC BY 4.0（国立国会図書館）です。OCR の誤認識はそのまま検索結果に影響します。
